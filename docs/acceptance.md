# گزارش پذیرش مرحلهٔ اول

تاریخ: ۲۰۲۶-۱۰-۲۸. مسیر پروژه: `D:\wortzeit\wortzeit`.

**وضعیت: پیاده‌سازی و یکپارچه‌سازی انجام شده؛ پذیرش کاملِ مرورگر/موبایل هنوز تأیید نشده است.** محدودیت ابزار را با موفقیت آزمون واحد جایگزین نکرده‌ایم.

این سند سابقهٔ مرحلهٔ اول است. commit مبنا `2038f67` اکنون وجود دارد؛ وضعیت جاری اصلاح تب دوم در [تثبیت](stabilization.md) و توسعه و پذیرش نسخهٔ۲ در [پذیرش مرحلهٔ دوم](phase-two-acceptance.md) ثبت می‌شود. نتایج تاریخی زیر شاهد موفقیت native مرورگر در نسخهٔ۲ نیستند.

## تحویل نقش‌ها

نقش‌های اختصاصی از پیش بارگذاری نشده بودند. سه ایجنت فرعی واقعی و مستقل با نام‌های `content`، `learning` و `ui` پس از تثبیت [قرارداد و مالکیت](phase-one-handoff.md) کار کردند. یک ایجنت `reviewer` مستقل، نتیجهٔ یکپارچه را فقط خواند و یافته داد. اصلی قرارداد، اتصال، صف commit/retry، PWA، تنظیمات و بررسی نهایی را انجام داد.

| نقش | فایل و رفتار | شاهد |
|---|---|---|
| content | `src/content/`: ۲۰ مدخل ثابت، تمام معنی/آرتیکل/ارجاعات موجود، مثال و جای خالی تألیفی، گزینه‌های معنی معتبر | ۵ آزمون؛ تطبیق دقیق با فایل گزیده |
| learning | `src/learning/` و `src/storage/`: جلسه، صف، ارزیابی، خطا، مرور و snapshot اتمی IndexedDB | ۱۳ آزمون موتور و ۴ آزمون اعتبار snapshot؛ transaction واقعی هنوز آزمون نشده |
| ui | `src/features/WortzeitUI.tsx` و سبک‌ها: خانه، کارت، معنی، جای خالی، اتصال، خلاصه، فهرست و ارجاع | TypeScript و lint؛ بررسی بصری مرورگر اجرا نشد |
| اصلی | `src/controller/`، App، PWA و scripts | آزمون چهار جلسهٔ واقعی بسته، دو آزمون شکست/retry، یک آزمون هویت cache؛ build و بررسی فایل‌های خروجی |
| reviewer | بررسی خواندنی نتیجهٔ یکپارچه | همهٔ یافته‌های مؤثر اصلاح و دوباره بازبینی شدند؛ مرورگر را تأیید نکرد |

## بررسی‌های اجراشده

- `npm test`: **۲۶ آزمون، ۲۶ موفق، صفر شکست و صفر skip**. شامل تقدم مرور، تأخیر سه پاسخِ مدخل دیگر، ماندگاری منطقی draft/feedback/صف، تکرار attemptId، جفت درست/غلط/تکراری، مرورهای ۱/۳/۷/۱۴/۳۰ و عدم پیشروی چندپله در روز.
- آزمون یکپارچهٔ داده و موتور، بستهٔ واقعی ۲۰ مدخلی را در چهار جلسهٔ پنج‌واژه‌ای طی می‌کند، هر snapshot را اعتبارسنجی و clone می‌کند و ادامه از سؤال و draft قبلی را می‌سنجد. این آزمون **IndexedDB واقعی یا بستن مرورگر نیست**.
- `npm run lint`: موفق، بدون خطا و هشدار.
- TypeScript در `npm run build:portable`: موفق. خروجی production با Vite/Rollup ساخته شد؛ ۳۹ ماژول و پوستهٔ ۹ asset. خروجی در `dist/` است و نسخهٔ portable کمینه‌سازی نشده است.
- `npm run verify:dist`: **۷ بررسی موفق**؛ وجود assetها، هویت یکسان HTML/کد/worker، ابعاد PNG، تأیید cache کامل، رد asset مفقود، حذف cache نصب ناموفق و fallback ناوبری آفلاین در شبیه‌سازی Node. این‌ها اجرای service worker در مرورگر نیستند.
- `npm run preview`: روی `http://127.0.0.1:4173/` اجرا شد. درخواست HTTP به صفحه، manifest، worker، JavaScript و CSS همگی **۲۰۰** و Content-Type مناسب داشتند.
- لینک‌های محلی اسناد و سازگاری دامنهٔ فعال با قرارداد اجرایی بررسی شدند.

## یافته‌های اصلاح‌شدهٔ بازبین

۱. حلقهٔ صف در مرز تغییر ساعت پاییزی برلین: پاسخ درست موعدرسیده در همان تاریخ مطالعه، پله را جلو نمی‌برد و دیگر پشت‌سرهم وارد صف نمی‌شود. آزمون ساعت کنترل‌شده اضافه شد.
۲. اصلاح نخست، مرور روزهای بعدِ همان جلسه را حذف می‌کرد؛ شرط حذف اکنون فقط همان تاریخ مطالعه است. آزمون توقف و ادامه دو روز بعد، حفظ سؤال/draft و تقدم مرور بر کارت جدید اضافه شد.
۳. retry موفقِ توقف اکنون رابط را از جلسهٔ paused به خانه می‌برد؛ دکمه‌های ظاهراً فعال با موتور متوقف باقی نمی‌مانند.
۴. صف commit فرمان ناموفق و همهٔ ویرایش‌های بعدی را حفظ می‌کند؛ retry متن کامل و همان attemptId را ذخیره می‌کند و پیش از commit موفقیت نشان نمی‌دهد.
۵. پوستهٔ جاری شناسهٔ build دارد؛ worker نسخهٔ قبلی نمی‌تواند آمادگی نسخهٔ تازه را تأیید کند. حالت نصب ناقص آماده نیست و پس از controllerchange دوباره بررسی می‌شود.

بازبین پس از اصلاح نهایی ایراد مؤثر تازه‌ای در کد گزارش نکرد.

## محدودیت‌های باقی‌ماندهٔ پذیرش

`npm run test:browser` تلاش شد و پیش از ایجاد مرورگر با **`browserType.launch: spawn EPERM`** متوقف شد. ابزار جایگزین نیز مرورگر متصل در دسترس نداشت و تلاش برای استفاده از مرورگر ویندوز با پیام نبود پشتیبانی از اجرای سیاست URL متوقف شد. مسیرهای مرورگر بیشتر ادامه داده نشدند.

بنابراین موارد زیر هنوز **تأیید تجربی ندارند**: اجرای کامل رابط در ۳۲۰/۳۶۰ پیکسل، نبود پیمایش افقی در مرورگر، لمس/صفحه‌کلید و کاهش حرکت واقعی، transaction/abort واقعی IndexedDB، دو تب و آزادشدن قفل، refresh/بستن/بازکردن واقعی، اجرای آفلاین و نصب PWA روی گوشی. هیچ تصویر آزمون موبایل یا نصب موفق ادعا نمی‌شود.

[اسکریپت مرورگر](../scripts/browser-test.mjs) برای محیط دارای اجازهٔ اجرای Chromium آماده است: نمای موبایل و بزرگ، جلسهٔ کامل و بازی، refresh، بستن/بازکردن آفلاین و draft، قفل تب دوم، transaction واقعی، abort و رقابت revision. تا اجرای موفق، این سناریوها «آمادهٔ آزمون» هستند و نتیجهٔ موفق ندارند. گزارش‌های اجرایی در `test-results/` تولید می‌شوند.

build عادی `npm run build` نیز در این محیط در ساخت پردازش esbuild با `spawn EPERM` متوقف شد. نصب وابستگی‌ها با cache محلی و `--ignore-scripts` انجام شد؛ `build:portable` تبدیل TypeScript و ثابت‌های همین برنامه را در همان پردازش انجام می‌دهد و مسیر مستقل و موفقِ ساخت است. build عادی و Playwright را می‌توان در ترمینال معمولیِ دارای مجوز اجرا بررسی کرد؛ نتیجهٔ آن هنوز در این محیط ثبت نشده است.

## وضعیت محتوا

منبع در `reference/vocabulary/Lesson-01-A1.txt` موجود بود. هر ۲۰ مدخل و تمام ارجاعات درج‌شدهٔ آن‌ها با همین فایل تطبیق یافتند. بسته `partial` و `excerpt-checked` است؛ PDFهای اصل و کل کتاب در این اجرا بررسی نشده‌اند. مثال‌ها و ترجمه‌های آن‌ها تألیفی‌اند. ویرایش کتاب و جمعِ ارائه‌نشدهٔ اسم‌ها صریحاً نامعلوم مانده‌اند. بازبینی انسانی نهایی آموزشی و تطبیق اصل منابع باقی است؛ پایان این بسته، پایان درس اول نیست.

## اجرا و تکمیل پذیرش

```powershell
cd D:\wortzeit\wortzeit
npm ci
npm run dev -- --host 0.0.0.0
```

برای خروجی ساخته‌شده در همین محیط:

```powershell
npm run build:portable
npm run verify:dist
npm run preview
```

در محیط دارای اجازهٔ اجرای مرورگر:

```powershell
npx playwright install chromium
npm run test:browser
```

برای گوشی فیزیکی، HTTPS و مرورگر مشخص لازم است؛ HTTP شبکهٔ محلی معمولاً PWA/Web Locks را فراهم نمی‌کند. مطالعهٔ PWA آفلاین بعد از نشان «آمادهٔ آفلاین» معنا دارد. درس‌های بعد، نمودار پیشرفته و یادآور پس‌زمینه ساخته نشده‌اند.
