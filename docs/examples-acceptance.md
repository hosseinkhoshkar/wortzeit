## تغییرات کد و داده

- دادهٔ جانبی نسخه۱ با sourceKey تخصیص‌یافته،row،word،meaningFa و دو جفتde/fa/authored. همهٔ metadata با مرجع تطبیق داده می‌شود و شناسهٔ آموزشی جدیدی نمی‌سازد.
- scripts/example-catalog.mjs فایل‌های موجود را کشف و تعداد/هویت/جفت‌ها/تمایز/تکرار سراسری را بررسی می‌کند. scripts/sync-examples.mjs دادهٔ معتبر را از طریق ثبت مرکزی درس‌های فعال به Entryهای همان درس‌ها وصل می‌کند. خروجی generated به شناسه‌های پایدار Entry متصل است. prebuild و prebuild:portable دادهٔ معتبر را همگام می‌کنند؛ متن معتبر موجود در فایل JSON بازنویسی نمی‌شود.
- src/content/extend-examples.ts مثال فعلی و همهٔ metadata/game data را حفظ می‌کند؛ اجرای دوباره، مثال را تکرار نمی‌کند. نبود داده یا برخورد شناسهٔ مثال fail-closed است.
- src/learning/examples.ts انتخاب جمله را از شمار reverseReviews کامل‌شدهٔ همان Entry محاسبه می‌کند:۱،۲،۰،۱... . هر self-assessment درست یا غلط یک رخداد کامل است؛ reveal/render/رفرش رخداد نیست.
- رابط فقط بعد از reveal، مثال منتخب و ترجمه‌اش را همراه یادآوری بلندخوانی نشان می‌دهد. معرفی اولیه فقط مثال فعلی دارد. «مثال‌های بیشتر» اختیاری است و فقط دیگر مثال‌ها را در dialog نمایش می‌دهد؛ در واژه‌نامه نیز در دسترس است. پیش از جوابِ کارت معکوس هیچ مثال یا دکمهٔ افشاگر وجود ندارد.
- schema۴،content identity،Entry IDs،Attempt،موعدها و queue قبلی تغییر نکرده‌اند؛ تاریخچهٔ موجود برای چرخش کافی است و migration تازه لازم نیست. بازی/نوشتن/جای خالی از همان پاسخ و مثال قبلی استفاده می‌کنند؛ تعداد سؤال زیاد نشده است.
- همهٔ۳۰JSON به artifact و cache همان build اضافه می‌شوند. دادهٔ جدید و فونت محلی آفلاین‌اند؛ نصب cache ناقص همچنان آمادگی اعلام نمی‌کند.

## بازبینی زبان

نویسندگان همهٔ جفت‌های محدودهٔ خود را از نظر کاربرد واژه/معنی هدف، صرف و حالت، ترجمه و تمایز مرور کردند. وابستگی‌های غیرضروری به واژه‌های محتوایی درس‌های بعد اصلاح شدند؛ در درس۱، Uhr و Euro به‌عنوان پایهٔ طبیعیِ مثال زمان/عدد باقی مانده‌اند. مرجع خود نیز ترتیب استخراج واژگان را از برنامهٔ دقیق دستور زبان کتاب تفکیک می‌کند؛ پیشروی نحویِ ارائه‌نشده حدس زده نشده است.

بازبینی مستقل کد و نمونه‌های زبانی A1/A2/B1 انجام شد؛ ترجمهٔ نامناسب Nachbar در درس۹ اصلاح شد. کنترل ساختاری و بازبینی نمونه‌ای، تضمین یا گواهی جامعِ دستور زبان توسط مدرس بومی نیست.

## بررسی دستی

۱. npm ci،npm run sync:examples،npm test،npm run lint و npm run build را اجرا کنید؛ برای آفلاین npm run preview روی localhost یا HTTPS لازم است.
۲. در یک درس فعال کارت را باز کنید: پشت کارت فقط مثال فعلی را دارد. «مثال‌های بیشتر» را باز کنید؛ دو مثال و ترجمه همراه برچسب تألیفی نمایش داده شوند. بستن پنجره نباید پاسخ یا موعدی ثبت کند.
۳. در کارت معکوس موعدرسیده ابتدا فقط فارسی دیده شود. پس از reveal، مثال منتخب و ترجمه دیده شوند. refresh/بازگشایی، مثال را عوض نکند؛ ارزیابی بعدی موعد را طبق قواعد قبلی تعیین می‌کند. در موعد بعد، جملهٔ بعدی می‌آید.
۴. در صفحهٔ کوچک، با مثال بلند و بازکردن جزئیات، دکمهٔ درست/غلط/بعدی باید قابل دسترس بماند. هیچ شمار سؤال یا امتیازی با بازکردن مثال‌ها اضافه نشود.
