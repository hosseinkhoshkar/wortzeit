# گرامر درس ششم: Kleider machen Freunde

درخواست مستقیم کاربر:۵۰ سؤال چهارگزینه‌ای برای درس6، تکمیل و push مستقل با نام درس، پیش از مرحلهٔ بعد.

## محتوا و منبع

۵۰ سؤال تألیفی با شناسه‌های ثابت a1-g06-001 تا a1-g06-050؛ امر رسمی Sie، پیشنهاد با wir، امر du/ihr، امرهای بی‌قاعده، پیشوندهای جداشدنی و پیشنهاد با sollen/wollen.
منبع مباحث: [نمونهٔ رسمی کتاب درسی Klett](https://www.vydavatelstvoklett.sk/uploads/61229686a3f39-probeseiten_a1_eb.pdf)، ISBN9783126761802، درس۶، صفحات چاپی۵۳،۵۵–۵۷ و۵۹.
locator هر سؤال به تمرین همان کتاب درسی اشاره می‌کند. سؤال و توضیح فارسی تألیفی است؛ این بسته ادعای رونویسی یا پوشش تمام تمرین‌های کتاب ندارد. هر سؤال از نظر صرف/نقش، معنا و وجود تنها یک پاسخ متناسب با قالب خواسته‌شده بازبینی شده است.

## سازگاری

به registry گرامر افزوده می‌شود؛ واژگان، ترتیب و هویت سؤال‌های قبلی، schema۴ و grammar.version=1 تغییر نمی‌کنند. جلسه، گزینه‌ها، پاسخ‌ها و آمار هر درس جدا می‌مانند. زمان فعال برای استریک مشترک است.

## بررسی و محدودیت

کنترل شمار۵۰، چهار گزینهٔ یکتا، حضور یک پاسخ معیار، شناسه‌های یکتا، پاسخ تکراری، قفل سؤال بعد، کامل‌کردن۵۰ سؤال در۱۰ نوبت، اولویت خطا، جدایی درس‌ها و حفظ پاسخ/گزینه‌های جلسه پس از شبیه‌سازی ذخیره انجام می‌شود.
تست‌های رگرسیون مخزن اضافه شده‌اند؛ محیط اجرای محلی در دسترس نیست، پس npm test/lint و مجموعهٔ کامل مرورگر قابل اجرا نیستند. بررسی منطق در محیط میزبانی‌شده با حذف annotationهای TypeScript جای مجموعهٔ کامل آزمون‌ها نیست. build واقعی و UI مرورگر پس از push بررسی می‌شوند و نتیجه در توضیح PR ثبت می‌شود.

نمونهٔ کامل درس۶، صفحات چاپی۵۲ تا۵۹ است. تطبیق اصلی: A3–4 صفحه۵۳، B5 صفحه۵۵، C3 صفحه۵۶، C4 صفحه۵۷، جدول جامع صفحه۵۹. پاسخ‌نامهٔ رسمی Kursbuch نیز برای مقابلهٔ دوم بررسی شد. صفت‌های رنگ در متن درس هستند، اما صرف صفت موضوع این مجموعه نیست.
