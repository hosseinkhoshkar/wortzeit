# پذیرش مرحلهٔ دوم

تاریخ: ۲۰۲۶-۱۰-۲۸؛ مبنا: `2038f67`؛ قرارداد: `data-contract-v2`.

**پیاده‌سازی و ادغام انجام شده؛ پذیرش مرورگر/گوشی و commit نهایی به محدودیت محیط وابسته و هنوز کامل نیستند.** داده‌های مدل، SSR و worker simulation شاهد مرورگر واقعی نیستند.

## رفتارهای تحویل‌شده

- همان۲۰ مدخل با شناسه، معنی، آرتیکل، مثال اصلی و تمام ارجاع‌های قبلی حفظ شده‌اند؛ نسخهٔ محتوا `lesson-01-excerpt-v2` و وضعیت همچنان `partial/excerpt-checked` است. کتاب یا درس جدیدی اضافه نشده است.
- آرتیکل فقط برای۱۰ اسم معلوم، با der/die/das و نمایش صورت صحیح+معنی پس از پاسخ. نوشتن واژه از prompt/سرنخ فارسی برای همهٔ مدخل‌های همین بسته.
- NFC و فاصله‌ها تحمل می‌شوند؛ case طبق مدخل است. صورت‌های جایگزین صریح Tschuess/heissen پذیرفته و صورت معیار نمایش داده می‌شود. حذف اوملاوت، غلط نزدیک یا صرف نامتناسب خودکار پذیرفته نمی‌شوند. تمایز معنایی Sie/sie در fixture جدا حفظ شده است.
- مهارت معنی، نوشتن و آرتیکل قابل اعمال جداست. تمرین دشواری‌ها پیش از جدیدها و حداکثر۵ جدید در جلسه؛ ترتیب نوشتن/جای خالی و گزینه‌ها seedدار است و صف محدود می‌ماند.
- کمک/نمایش پاسخ، رویداد ماندگار و dedup دارد. پاسخ پس از کمک و حدس مجدد اتصال مستقل نیستند. بازکردن فهرست برای سؤال ناتمام نیز پیش از نمایش، کمک ثبت می‌کند؛ حتی در pause و برای هر جفت حل‌نشدهٔ اتصال. آمار درستِ بدون کمک با مراجعه به مرجع افزایش کاذب نمی‌گیرد.
- موعد فقط در `learning/schedule.ts` تعیین می‌شود؛ نخست +۱ و سپس +۳، +۷، +۱۴، +۳۰ روز، بدون چندپله در روز. تثبیت سه تاریخ مستقلِ موعدرسیده و برای اسم یک پاسخ آرتیکل بدون کمک می‌خواهد؛ خطا/کمک زنجیره را لغو می‌کند و مرور۳۰روزه باقی است.
- زمان از performance.now و فقط نمای جلسهٔ فعال/visible می‌آید. هدف روزانه۲۰ دقیقه پیشنهاد پایان می‌دهد و ادامه مجاز است. تأیید ادامه به همان تاریخ مطالعه تعلق دارد؛ روز بعد دوباره پیشنهاد ممکن است. pause/hidden/غیبت و تعلیق طولانی شمرده نمی‌شوند و نیمه‌شب سهم روزها را جدا می‌کند.
- مهاجرت schema۱→۲ در transaction واحد، با حفظ rawanswer/result، attemptId، entryId، موعد، پله، تاریخ‌ها، queue/cursor/draft/feedback. مهارت‌ها از شواهد قبلی استخراج و زمان قدیمی صفر می‌شود؛ تاریخچه دوباره نمره‌دهی نمی‌شود. کمکِ حدس‌های تکراری قدیمی از تاریخچه قابل استنتاج است. شکست migration، v1 را حفظ می‌کند؛ نسخهٔ ناشناخته/خراب reset نمی‌شود. پشتیبان یا کلید backup جدیدی ساخته نشده است.
- اصلاح قفل و retry تب دوم، توقف امن writer و تشخیص خطا در [گزارش تثبیت](stabilization.md) آمده است.

## همکاری و بازبینی

قرارداد و مالکیت در [handoff](phase-two-handoff.md) پیش از واگذاری مشخص شدند. ایجنت‌های واقعی content، learning و ui در محدوده‌های مستقل کار کردند؛ هماهنگ‌کننده App/controller/زمان/اتصال/اسناد و scripts را ادغام کرد. reviewer مستقل، نتیجهٔ یکپارچه را فقط خواند. فایل مشترک هم‌زمان دو مالک نداشت.

یافته‌های مؤثر برطرف شدند: بستن و دوباره‌بستن writer پیش از آزادکردن قفل؛ هدف روزانهٔ چندروزه؛ کمک از واژه‌نامه در حالت فعال و paused؛ افشای چند جفت بازی در مرجع؛ تطبیق متن راهنمای case با ارزیابی. بازبین مستقل پس از آخرین اصلاح، یافتهٔ مؤثرِ باز دیگری گزارش نکرد؛ محدودیت اجرای مرورگر را نیز صریح نگه داشت.

## گیت‌های اجرا

- `npm test`: اجرای نهایی **۵۹ موفق، صفر شکست و صفر skip**؛ شامل آزمون منبع/محتوا، موتور و زمان کنترل‌شده، مهاجرت و مدل IDB، writer/قفل، flow واقعی۲۰مدخلی و پنج آزمون React SSR.
- `npm run lint` و TypeScript (`tsc -b` در build production): موفق؛ شش خطای unused در fixture مهاجرت بدون تضعیف قواعد lint اصلاح شدند.
- `npm run build:portable`: TypeScript و production Vite/Rollup موفق؛ ۴۴ ماژول و۹ asset ضروری آفلاین. خروجی portable کمینه‌سازی نشده است.
- `npm run verify:dist`: هفت بررسی artifact/worker موفق؛ هویت HTML/کد/worker، ابعاد icon، cache کامل، رد asset مفقود، نصب ناموفق و fallback آفلاین در شبیه‌سازی Node.
- `npm run test:browser`: پس از بازسازی خروجی تلاش شد و پیش از ایجاد context با `browserType.launch: spawn EPERM` متوقف شد. اجرای مستقل ایجنت مرورگر نیز همین محدودیت داشت.

آزمون‌های clock/LockManager/IDB مدل کنترل‌شده‌اند. SSR فقط محتوا/عدم افشای زودهنگام/جهت ورودی/برچسب‌ها را بررسی می‌کند؛ کلیک، لمس، هندسهٔ۳۶۰پیکسل یا Web Locks واقعی را ثابت نمی‌کند.

## محدودیت‌های واقعی

مرورگر موبایل‌شبیه‌سازی‌شده، گوشی فیزیکی، IndexedDB/abort واقعی، دو تب واقعی، حفظ پس از refresh/close واقعی، آفلاین واقعی و نصب PWA هنوز شاهد اجرای موفق ندارند. اسکریپت مرورگر سناریوهای دو تب، صف و draft، آفلاین، تمرین نوشتن و آرتیکل و خطاهای همهٔ صفحات را آماده دارد؛ تا اجرای مجاز، این‌ها نتیجهٔ موفق ندارند. علت native timeout قبلیِ تب دوم نیز قطعی اعلام نمی‌شود.

نمونهٔ فعالیت حداکثر۵ثانیه است؛ شکاف طولانی event loop/تعلیق قابل تأیید نیست و محافظه‌کارانه کنار گذاشته می‌شود. صحت جامع اصل PDFهای کتاب و بازبینی انسانی نهایی زبان باقی است. old reader۱ پس از نوشتن۲ صریحاً رد می‌کند؛ downgrade بدون تبدیل معکوس مسیر پشتیبانی‌شده نیست.

Git: commit مبنا موجود است، ولی ساخت شاخهٔ codex/ و index/commit جدید با محدودیت نوشتن `.git` متوقف‌اند. تغییرها در working tree هستند؛ push یا انتشار انجام نشده است. این محدودیت با موفقیت build یا آزمون‌ها حل‌شده محسوب نمی‌شود.

```powershell
cd D:\wortzeit\wortzeit
npm ci
npm run dev -- --host 0.0.0.0
```

برای همین محیط محدود:

```powershell
npm run build:portable
npm run verify:dist
npm run preview
```

در محیط مجاز برای مرورگر: `npx playwright install chromium` و `npm run test:browser`. برای گوشی، HTTPS لازم است؛ HTTP شبکهٔ محلی معمولاً قفل و service worker ندارد. آمادگی آفلاین فقط پس از نشان تأیید cache همان build معنا دارد.
