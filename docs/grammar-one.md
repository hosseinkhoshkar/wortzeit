# گرامر چهارگزینه‌ای درس۱

درخواست: شروع از درس۱، فقط سؤال تستی با چهار گزینه؛ بدون ورودی نوشتاری یا مرتب‌کردن تعاملی.

- ۲۴ سؤال تألیفی در شش گروه: sein، صرف فعل، خطاب رسمی/دوستانه، ضمیرهای شخصی، پرسش‌واژه‌ها و ترتیب جمله/سؤال.
- مباحث با نمونهٔ کتاب DaF kompakt A1–B1، ISBN9783126761802، صفحات چاپی۱۰ تا۱۷ مقابله شدند. پیوند و محدوده در src/content/grammar-one.ts ثبت است. سؤال‌ها نقل‌قول از تمرین‌های کتاب نیستند.
- هر نوبت۵ سؤال یکتا و چهار گزینه با ترتیب seedدارِ ماندگار دارد. پاسخ فقط یک‌بار و پس از ذخیره نهایی می‌شود. سپس جواب درست و توضیح فارسی و دکمهٔ سؤال بعدی می‌آیند.
- سابقهٔ گرامر از واژگان جداست؛ آخرین پاسخ غلط در انتخاب نوبت بعد اولویت دارد. این امتیاز تسلط نوشتاری یا مرور واژگان محسوب نمی‌شود.
- فیلد اختیاری grammar در همان snapshot IndexedDB، همان صف writer و همان قفل ذخیره می‌شود. schema۴ و contentVersion قبلی حفظ‌اند؛ ذخیرهٔ قدیمی فاقد این فیلد بدون تغییر خوانده می‌شود. دادهٔ نامعتبر رد می‌شود، نه reset.
- دو جلسه هم‌زمان فعال نمی‌شوند. زمان گرامر از ActivityTracker موجود می‌آید و فقط همان جلسهٔ فعال و قابل مشاهده برای استریک حساب می‌شود؛ pause/hidden و آفلاینِ بسته زمان نمی‌سازند.
- مسیر «گرامر» در ناوبری اضافه شده؛ فعلاً فقط درس۱ آماده است. درس‌های دیگر صریحاً آماده‌نبودن را نشان می‌دهند و به درس۱ پیوند دارند.
- سؤال‌ها همراه bundle اپ بسته‌بندی می‌شوند؛ backend، API یا dependency اضافه نشده است.

## بررسی انجام‌شده و باقی‌مانده

محیط executor در این درخواست در دسترس نبود. ساختار داده و منطق خالص مدل، پس از حذف annotationهای TypeScript، در JavaScript میزبانی‌شده با۴۰ seed و۲۰۰ پاسخ بررسی شد: چهار گزینهٔ یکتا،۵ سؤال یکتا، چهار جایگاه پاسخ درست، پایان نوبت، جلوگیری از ثبت تکراری و اولویت خطاها گذشتند. این بررسی جای اجرای فایل‌های تست اصلی، TypeScript، lint، build، React یا مرورگر نیست.

تست‌های Node برای داده/مدل/اتصال موتور/استریک و IndexedDB، تست SSR رابط و checkpoint مرورگر نوشته شده‌اند ولی در این محیط اجرا نشده‌اند. شاخه باید قبل از ادغام از npm test، npm run lint، npm run build، npm run verify:dist و npm run test:browser بگذرد. به‌خصوص viewportهای۳۲۰×۵۶۸،۳۶۰×۸۰۰ و۳۹۰×۸۴۴ و اثر ناوبری پنج‌تایی بازبینی شوند. انتشار main بخشی از این خروجیِ بررسی‌نشده نیست.
