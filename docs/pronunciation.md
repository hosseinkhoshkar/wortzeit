# تلفظ با صدای مرورگر

دامنهٔ این مرحله: پخشِ اختیاری متن آلمانیِ آشکار با Web Speech API و صداهای خود مرورگر. موتور، schema۴، دادهٔ واژگان، چرخش مثال‌ها و cache تغییری نمی‌کنند؛ وابستگی، درخواست TTS برنامه، حساب یا بکاند اضافه نمی‌شود.

معیار پذیرش: دکمهٔ مستقل و قابل دسترسی برای واژهٔ روی فلش‌کارت (آرتیکل معلوم همراه اسم؛ مصدر کاملِ ذخیره‌شده برای فعل) و جمله‌های renderer مشترک. مرور معکوس فقط پس از reveal، با واژه و همان مثال منتخب. کنترل صوت نباید جواب پنهان سایر تمرین‌ها را آشکار، کارت را برگرداند یا command یادگیری ارسال کند.

یک پخش‌کنندهٔ مشترک، انتخاب صریح صدای de-DE و سپس صدای دیگر آلمانی، دریافت voiceschanged، توقف با همان دکمه و جایگزینی با دکمهٔ دیگر. خروج از کارت/درس/صفحه و بستن پنجرهٔ آغازکننده، صوت همان محدوده را لغو می‌کند؛ callback لغوشده بی‌اثر است. نبود API/صدای آلمانی و خطای پخش، پیام کوتاه فارسی دارند.

سرعت «عادی» 1.0 و «آهسته» 0.8 برای واژه و جمله مشترک‌اند. تنها ترجیح مستقل localStorage با کلید `wortzeit-pronunciation-rate` ذخیره می‌شود؛ مقدار نامعتبر یا ذخیرهٔ غیرقابل دسترس به عادی برمی‌گردد. وجود صدا و پخش آفلاین به دستگاه و صدای نصب‌شده بستگی دارد؛ آماده‌بودن cache برنامه تضمین صوت آفلاین نیست.

بررسی: mock API برای متن/صدا/بارگذاری دیررس/نبود پشتیبانی/سرعت و ذخیره/لغو و callback کهنه؛ آزمون نمایشِ پاسخ پنهان؛ مرورگر برای لمس و کیبورد، استقلال پیشرفت و مثال، بستن پنجره و خروج. npm test، lint و build و در صورت دسترسی Chromium، test:browser. شنیدن واقعی صدا روی Chrome دسکتاپ و Android نیازمند بررسی دستی است و با mock اثبات نمی‌شود.

## بررسی دستی صدا

در Chrome دسکتاپ و Chrome یک گوشی Android، با صدای آلمانیِ در دسترس دستگاه:

1. فلش‌کارت اسم را باز کن و بلندگو را بزن؛ آرتیکل معلوم باید همراه اسم شنیده شود. برای فعل جداشدنی مثل fernsehen، مصدر کامل شنیده شود. لمس بلندگو نباید کارت را برگرداند.
2. پشت کارت، مثال فعلی مرور معکوس و هر دو جملهٔ «مثال‌های بیشتر» را بشنو. قبل از نمایش پاسخ مرور معکوس، هیچ بلندگویی نباشد. واژه/مثال منتخب و پیشرفت هنگام پخش ثابت بمانند.
3. سرعت عادی و آهسته را مقایسه کن؛ پس از refresh انتخاب سرعت حفظ شود. با همان بلندگو توقف، با بلندگوی دیگر جایگزینی، و با بستن پنجره یا خروج از کارت/درس، قطع صدا را بررسی کن. آفلاین را جدا روی همان دستگاه امتحان کن؛ cache برنامه به‌تنهایی شاهد صدای آفلاین نیست.
