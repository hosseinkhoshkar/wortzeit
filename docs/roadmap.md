# نقشهٔ کار و پذیرش

مرحلهٔ اول، مسیر همان۲۰ مدخل با کارت/معنی/جای خالی/اتصال و ذخیرهٔ محلی را ایجاد کرد. commit مبنای آن `2038f67` است. [گزارش مرحلهٔ اول](acceptance.md) سابقهٔ اجرا و محدودیت‌های آن را نگه می‌دارد.

درخواست فعال: [تلفظ متن آشکار با Web Speech API](pronunciation.md)، بدون تغییر schema۴ یا قواعد یادگیری و چرخش مثال‌ها. تغییرها برای بررسی در working tree می‌مانند.

## پیش‌نیاز تثبیت

retry تب دوم، قفل نویسندهٔ واحد، جمع‌کردن startup معلق و صف ذخیره، و شواهد تشخیصی آزمون مرورگر در [گزارش تثبیت](stabilization.md) پیگیری می‌شوند. نتیجهٔ مدل و EPERM نباید موفقیت native مرورگر نامیده شوند.

## مرحلهٔ دوم فعال

[قرارداد و مالکیت](phase-two-handoff.md) پیش از کار موازی تثبیت شده است؛ هماهنگ‌کننده مالک typeها، App، controller و اتصال است؛ learning مالک learning/storage و آزمون‌هایش، content مالک محتوای موجود/اعتبارسنجی، ui مالک features/components/سبک‌ها و reviewer فقط خوانندهٔ نتیجهٔ یکپارچه است. فایل مشترک یک مالک فعال دارد.

موارد بالا سابقهٔ مرحلهٔ دوم‌اند. درخواست تأییدشدهٔ بعدی کاربر، افزودن درس چهارم و بخش مستقل هر درس است و ارسال به GitHub را هم مجاز کرده است.

## مرحلهٔ سوم: درس چهارم و دسترسی مستقل درس‌ها

- تمام۸۴ مدخل فایل درس۴، با مثال تألیفی و تمرین‌های متناسب با نقش.
- حفظ همان۲۰ هویت و محتوای قبلی درس۱.
- کارت‌های مستقل درس‌ها، آمار، فهرست واژه و انتخاب مستقیم درس۴.
- حفظ جلسه/متن پاسخ هر درس هنگام جابه‌جایی؛ هدف زمانی روزانه مشترک.
- مهاجرت نسخه‌دار۱/۲ به۳ بدون پاک‌کردن سوابق.
- آزمون تمام۸۴ مدخل در مسیر واقعی موتور، مهاجرت و جابه‌جایی مرورگر، آفلاین و نمای موبایل.
- بازبینی مستقل، commit و push پس از گذر آزمون‌ها. گزارش مرحله در `lesson-four-acceptance.md` ثبت می‌شود.

درس‌های۲ و۳ محتوای برنامه ندارند و به‌عنوان درس آماده نمایش داده نمی‌شوند. نمودار، یادآور و پشتیبان‌گیری در این مرحله اضافه نمی‌شوند.
