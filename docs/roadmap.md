# نقشهٔ کار و پذیرش

مرحلهٔ اول، مسیر همان۲۰ مدخل با کارت/معنی/جای خالی/اتصال و ذخیرهٔ محلی را ایجاد کرد. commit مبنای آن `2038f67` است. [گزارش مرحلهٔ اول](acceptance.md) سابقهٔ اجرا و محدودیت‌های آن را نگه می‌دارد.

## پیش‌نیاز تثبیت

retry تب دوم، قفل نویسندهٔ واحد، جمع‌کردن startup معلق و صف ذخیره، و شواهد تشخیصی آزمون مرورگر در [گزارش تثبیت](stabilization.md) پیگیری می‌شوند. نتیجهٔ مدل و EPERM نباید موفقیت native مرورگر نامیده شوند.

## مرحلهٔ دوم فعال

[قرارداد و مالکیت](phase-two-handoff.md) پیش از کار موازی تثبیت شده است؛ هماهنگ‌کننده مالک typeها، App، controller و اتصال است؛ learning مالک learning/storage و آزمون‌هایش، content مالک محتوای موجود/اعتبارسنجی، ui مالک features/components/سبک‌ها و reviewer فقط خوانندهٔ نتیجهٔ یکپارچه است. فایل مشترک یک مالک فعال دارد.

| معیار | شاهد لازم |
|---|---|
| B01 | آرتیکل فقط برای اسم معلوم؛ پس از پاسخ، صورت صحیح و معنی؛ مهارت جدا از معنی |
| B02 | نوشتن با سرنخ روشن، NFC/whitespace، case طبق مدخل، صورت جایگزین صریح و رد املای غلط/صرف نامتناسب |
| B03 | حفظ تمرین‌های قبلی و صف محدود؛ تنوع seedدار با تقدم مرور و دشواری؛ سقف۵ جدید |
| B04 | ضعف معنی/نوشتن/آرتیکل به تمرین مناسب منجر شود؛ دادهٔ ناکافی تمرین جعلی نسازد |
| B05 | کمک/نمایش جواب و حدس مجدد مستقل نباشند؛ eventId و assisted ماندگار، بدون ساخت غلط مصنوعی |
| B06 | فقط موتور مرکزی موعد را تعیین کند؛ ۱،۳،۷،۱۴،۳۰ و ادامه۳۰؛ عدم چند پله در روز، DST و ادامهٔ چندروزه |
| B07 | تثبیت از سه روز مرور مستقل بدون خطا/کمک و آرتیکل قابل اعمال؛ موعد/خطای باز اولویت داشته باشد |
| B08 | زمان monotonic فقط جلسهٔ active/visible؛ pause/hidden/غیبت صفر، نیمه‌شب درست؛ هدف پیشنهاد و ادامه مجاز |
| B09 | migration نسخه‌دار۱→۲، حفظ rawattempt/result/شناسه/موعد/پله/صف/cursor/draft و رد خرابی بدون reset |
| B10 | commit اتمی و retry/dedup؛ حفظ draft و ادامه پس از refresh/بازکردن؛ تک‌نویسنده و لغو startup معلق |
| B11 | cache همان build و آفلاین production؛ به‌روزرسانی حافظهٔ کاربر را پاک نکند |
| B12 | مسیر جلسه در viewport موبایل، همهٔ تمرین‌ها و کنترل‌های لمس/RTL/LTR؛ کاهش حرکت و بازخورد مستقل از رنگ |
| B13 | آزمون‌ها، lint، TypeScript و build production؛ بازبین مستقل و گزارش محدودیت واقعی |

آزمون Node و شبیه‌سازی worker جای مرورگر و گوشی فیزیکی نیستند. گیت اجراشده و اجرا‌نشده جدا ثبت شوند؛ پایان بسته پایان کل درس نیست. بازبینی جامع PDFهای اصل همچنان باقی است.

درس جدید، نمودار، یادآور و پشتیبان‌گیری در این مرحله ساخته نمی‌شوند. push انجام نمی‌شود و ثبت نهایی Git باید محلی و روی شاخهٔ codex/ باشد؛ محدودیت نوشتن Git، در صورت تداوم، صریح گزارش می‌شود.
