# بازطراحی و رفع باگ جلسه

درخواست کاربر ۲۰۲۶-۱۰-۳۱؛ بررسی نهایی ۲۰۲۶-۱۱-۰۱.

## تغییرات

- خانهٔ خلوت‌تر، پالت یاسی/نعنایی/مرجانی، تصویر کارت و فونت فارسی Vazirmatn محلی با مجوز OFL. اطلاعات مفصل در درس‌ها، واژه‌ها و دربارهٔ درس باقی می‌مانند.
- ذخیرهٔ فعالیت هرثانیه و متن پاسخ دیگر busy سراسری ایجاد نمی‌کند؛ فرمان‌های واقعی همچنان هنگام ثبت محافظت می‌شوند. شکست ذخیره و retry با همان فرمان/شناسه حفظ می‌شود.
- حذف چرخش سه‌بعدی کارت و افکت blur ناوبری موبایل؛ فضای scrollbar ثابت و بازگشت به بالای صفحه هنگام تغییر بخش.
- مرورهای موعدرسیده و ضعف‌ها اولویت دارند؛ سپس همهٔ حداکثر۵ کارت جدید و بعد تمرین همان دسته. تعداد مرور بر اساس موعد واقعی است، نه پنج مرور تصادفی. کارت‌های قبلی دوباره جدید نمی‌شوند.
- اتصال با بازخورد کوتاه خودکار ادامه دارد؛ دو گزینهٔ غلط قرمز و دوباره قابل انتخاب می‌شوند. پس از آخرین جفت، ادامه خودکار است. راهنمای بازی در حین بازخورد حذف نمی‌شود تا ارتفاع صفحه نپرد. زمان‌سنج هنگام پنهان‌شدن تب یا خروج از جلسه متوقف می‌شود.
- schema۳، شناسه‌ها و صف جلسه‌های ذخیره‌شده عوض نشده‌اند؛ جلسهٔ قدیمی با ترتیب قدیمی ادامه پیدا می‌کند. بازچینی فقط برای جلسه‌های تازه است.

## شواهد

- ۸۴ آزمون Node موفق، صفر شکست/skip؛ شامل موتور، تمام محتوای دو درس، مهاجرت، ذخیره، قفل و retry.
- lint، build و verify:dist موفق؛ cache شامل فونت محلی است.
- ۱۱ سناریوی مرورگر موفق در Chromium 153 headless با Playwright؛ عرض‌های ۳۲۰،۳۶۰،۴۳۰ و۱۲۸۰ بدون پیمایش افقی، ذخیرهٔ واقعی زمان بدون تغییر disabled/scroll، پنج کارت قبل از تمرین، اتصال غلط و retry کمکی و ادامهٔ خودکار، ثبات ارتفاع بازی، آفلاین و بازگشایی، حفظ draft، مهاجرت نسخه۲، جداسازی درس‌ها و قفل دو تب. خطای JavaScript صفحه ثبت نشد.
- تصاویر خانهٔ موبایل/دسکتاپ، پشت کارت و بازی بازبینی بصری شدند. بررسی مستقل دو مشکل retry و ارتفاع راهنما را مشخص کرد و هر دو رفع شدند.
- نصب Chromium استاندارد از CDN در این محیط موفق نبود؛ مرورگر از بستهٔ موقت @sparticuz/chromium استخراج و از WORTZEIT_CHROMIUM_PATH اجرا شد. این بسته جزو وابستگی برنامه نیست. برای استفاده از مسیر مرورگر سفارشی: WORTZEIT_CHROMIUM_PATH=/path/to/chromium npm run test:browser.

آزمون مرورگر با اندازهٔ موبایل جای آزمون روی گوشی واقعی یا تأیید نهایی انتشار Vercel نیست. مرورگر قدیمی با service worker باز ممکن است برای دریافت نسخهٔ تازه به بستن و بازکردن برنامه نیاز داشته باشد؛ دادهٔ سایت پاک نشود.
