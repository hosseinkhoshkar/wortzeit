# قرارداد اجرایی و مالکیت مرحلهٔ اول

درخواست مستقیم ۲۰۲۶-۱۰-۲۸ جایگزین انتخاب‌های اولیهٔ ۸ مدخل، سقف روزانهٔ ۴ مدخل و تعویق بازی‌هاست. مرحلهٔ فعال: ۲۰ مدخل از `reference/vocabulary/Lesson-01-A1.txt`، حداکثر ۵ مدخل جدید **در هر جلسه**، فلشکارت، انتخاب معنی، جای خالی و اتصال چهار جفت. نوشتن واژه و آرتیکل به‌صورت تمرین جدا، درس بعد، نمودار و یادآور پس‌زمینه خارج از این مرحله‌اند.

قرارداد مشترک `data-contract-v1` در `src/contracts/index.ts` اجرایی است؛ بسته و سیاست جدا نسخه دارند. شناسهٔ مدخل ثابت است. بررسی محتوا فقط تطبیق با گزیدهٔ موجود است؛ تأیید جامع اصل کتاب نیست. مثال‌ها تألیفی‌اند. دادهٔ پیشرفت در IndexedDB و محتوا در بستهٔ ثابت برنامه است.

| مالک | فایل‌ها | ورودی و خروجی |
|---|---|---|
| اصلی | `docs/`، `src/contracts/`، `src/controller/`، `src/App.tsx`، `src/pwa/`، `public/`، `scripts/`، تنظیمات و package | قرارداد، اتصال، صف ثبت و retry، PWA، build و پذیرش یکپارچه |
| content | `src/content/` | منبع درس + قرارداد ← بستهٔ ۲۰ مدخلی و اعتبارسنج/آزمون تطبیق منبع |
| learning | `src/learning/`، `src/storage/` و آزمون‌های همان محدوده | قرارداد + بسته + زمان تزریق‌شده ← موتور خالص و ذخیرهٔ اتمی state با کنترل revision |
| ui | `src/features/`، `src/components/`، `src/App.css`، `src/index.css` | `WortzeitUIProps` ← خانه، جلسه، خلاصه، فهرست و بازخورد؛ بدون قاعدهٔ مستقل مرور |
| reviewer | نتیجهٔ یکپارچه، فقط خواندن | بررسی رفتارها، اجرا و یافته‌های دارای شاهد؛ بدون ویرایش هم‌زمان |

`learning` مالک ذخیرهٔ محلی نیز هست؛ این واگذاری صریح مرز پیش‌فرض AGENTS.md است. فایل‌های مشترک و `package.json` فقط در اختیار اصلی‌اند. تغییر type با هماهنگی اصلی انجام می‌شود.

فاصله‌ها: پس از یادآوری مستقل نخست +۱ روز، سپس مرور مستقلِ موعدرسیده در روز جدا +۳، +۷، +۱۴ و +۳۰ روز؛ پس از آن +۳۰. فقط جای خالی بدون راهنما پله را افزایش می‌دهد. کارت و بازی مدرک تسلط نیستند. خطا پله را صفر، موعد را نزدیک و تکرار را پس از سه پاسخ به مدخل‌های دیگر می‌کند. اگر سؤال کافی نباشد، خطا برای جلسهٔ بعد می‌ماند. تکرار همان attemptId بی‌اثر است. پاسخ، cursor، feedback و موعد در یک commit ذخیره می‌شوند؛ شکست ذخیره پیشرفت موفق نمایش نمی‌دهد.

پذیرش: منبع/معنی/آرتیکل/تمام ارجاعات ۲۰ مدخل، برچسب مثال؛ سقف پنج و تقدم مرور؛ پاسخ غلط و تأخیر؛ ساعت کنترل‌شده و جلوگیری از چند پله در روز؛ جفت‌های درست و غلط؛ idempotency و ذخیره/بازیابی/خرابی؛ مسیر واقعی مرورگر در ۳۶۰ پیکسل، refresh و بازشدن دوباره؛ cache production و آفلاین؛ lint و build. شواهد و محدودیت دستگاه واقعی جدا ثبت می‌شوند.
