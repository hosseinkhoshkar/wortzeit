# درس پنجم: Endlich ein Zimmer! / بالاخره یک اتاق!

درخواست ۲۰۲۶-۱۱-۰۵: افزودن درس۵ به کاتالوگ موجود، با همان مسیر مشترک درس۴. انتشار و commit جزو این مرحله نیستند.

## دامنه و قرارداد پذیرش

- دقیقاً۷۶ مدخل فایل `reference/vocabulary/Lesson-05-A1.txt`، با حفظ ترتیب، صورت آلمانی، معنی، آرتیکل معلوم و تمام ارجاع‌ها؛ شناسه‌های پایدار `a1-l05-001` تا `a1-l05-076` و lessonId=`lesson-05`.
- منشأ `partial` / `excerpt-checked`؛ هر مدخل یک مثال تألیفی دوزبانه و دو مثال موجود sidecar با `sync:examples`. مرجع و sidecar دست‌نخورده می‌مانند.
- درس‌های فعال۱،۴،۵ با شمار۲۰،۸۴،۷۶ و مجموع۱۸۰؛ کارت/آمار/فهرست مستقل و پیوند مستقیم `?lesson=lesson-05`.
- استفاده از UI، موتور و ذخیرهٔ مشترک برای همهٔ تمرین‌ها، مرور نوشتاری و معکوس، چرخش مثال، مثال‌های بیشتر و تلفظ. سقف۵ جدید، هدف روزانهٔ مشترک و cache تأییدشده حفظ می‌شوند.
- متن ناتمام، سؤال و صف هر دو درس۴ و۵ پس از جابه‌جایی و reload باقی بمانند. جواب معکوس و کنترل صوتی آن پیش از reveal پنهان باشند.
- معنی‌های یکسان منبع (Bad/Badezimmer) حفظ می‌شوند؛ یکتایی معنی شرطِ گزینه‌های هر سؤال و چهار جفت هر صفحهٔ اتصال است، نه کل درس. صف تازه از میان مدخل‌های معرفی‌شده/در حال معرفی، نخستین چهار معنی متمایز را انتخاب می‌کند؛ صف ذخیره‌شده تغییر نمی‌کند.
- جای خالی همان cueFa نوشتن را کنار ترجمه نشان می‌دهد؛ برای دو صورت حمام و فعل‌های نزدیکِ آوردن، صورت هدف روشن می‌شود و جواب آلمانی آشکار نمی‌شود.
- schema۴، شناسه‌های قبلی و `course-a1-lessons-01-04-v1` حفظ می‌شوند: validator فعلی برابری دقیق نسخهٔ محتوا را لازم دارد. نام تاریخی این رشته شناسهٔ سازگاری ذخیره است، نه شمار درس‌های فعال. داده‌های اجرایی و cache با build تازه می‌شوند.
- fixture `src/storage/fixtures/pre-lesson-five-schema4.json` پیش از افزودن درس۵، با موتور checkout `5cb293f` تولید شد:۲۰ پیشرفت،۶۳ پاسخ،۲ مرور معکوس، جلسهٔ۴ و جلسهٔ بایگانی‌شدهٔ۱، هر دو دارای draft. بارگذاری آن نباید revision، تاریخچه، موعد یا صف را بازنویسی کند. readerهای قدیمی۱/۲/۳ حفظ می‌شوند.

## بررسی

نتایج نهایی در ۲۰۲۶-۱۱-۰۵:

| گیت | نتیجه |
|---|---|
| `npm run sync:examples` | موفق؛۳۰ فایل،۱۳۳۳ ردیف،۲۶۶۶ مثال جانبی،۱۸۰ Entry فعال؛ بدون مورد پردازش‌نشده |
| `npm test` | ۱۳۶ موفق، صفر شکست/skip؛ از جمله تطبیق۷۶ ردیف، سه مثال هر مدخل، کاتالوگ۱۸۰، همهٔ۷۶ واژه طی۱۶ جلسه، و eligibility آرتیکل |
| `npm run lint` | موفق |
| `npm run build` | موفق، build عادی production؛۴۱ asset، cache=`86122c580d0b4a1a` |
| `npm run verify:dist` | هر۷ بررسی artifact/worker موفق |
| `npm run test:browser` | هر۱۸ سناریو در Chromium موفق؛ گزارش کامل در `test-results/browser-report.json` و `browser-report-full.json` |
| بررسی متمرکز کیبورد | موفق؛ checkpoint مربوط به cue درس۵ با اجبار اجرای بررسی مستقل برای Bad، Badezimmer و bringen؛ گزارش `test-results/browser-report-lesson-five-cloze.json` |
| اسناد و diff |۴۹ پیوند محلی سالم؛ `git diff --check` موفق |

آزمون محتوا و بازبینی مستقل:۷۶ ردیف،۱۲۳ ارجاع،۳۸ آرتیکل معلوم و۲۲۸ مثال دوزبانهٔ درس۵ (۷۶ اولیه و۱۵۲ sidecar). مرجع درس۵، sidecar و فایل‌های محتوای قبلی درس۱/۴ بدون diff هستند؛ دادهٔ تولیدشدهٔ `src/content/additional-examples.ts` فقط افزوده شده است.

آزمون ذخیره، fixture نسخه۴ را بدون migration یا تغییر revision/پیشرفت/موعد/صف/draft/تاریخچه بارگذاری می‌کند. آزمون‌های نسخه‌های۱/۲/۳ نیز در کاتالوگ واقعی سه‌درس اجرا شدند. جابه‌جایی۴↔۵ با هر دو draft و صف، reload و ثبت دوبارهٔ snapshot در مدل IndexedDB بررسی شد؛ هدف زمانی روزانه همچنان مشترک است. در Chromium نیز ذخیرهٔ قدیمی پیش از ورود مستقیم۵ حفظ شد و بازگشت به سؤال و draft هر درس، ادامهٔ آفلاین و مثال‌های بیشتر موفق بودند.

مرور معکوسِ واژه‌های واقعی درس۵، پنهان‌بودن پاسخ و مثال‌ها/صوت تا reveal، تلفظ واژه و هر سه مثال، سرعت و لغو پخش و بی‌اثر بودن مثال‌ها بر پیشرفت بررسی شدند. API گفتار در آزمون مرورگر شبیه‌سازی شده است؛ کیفیت شنیداری صدای واقعی یا وجود صدای آلمانی روی هر دستگاه تأیید نشده است. نمای۳۲۰×۵۶۸،۳۶۰×۸۰۰ و۳۹۰×۸۴۴ و viewport کیبورد شبیه‌سازی‌شده بررسی شدند؛ گوشی فیزیکی یا نصب PWA روی آن اجرا نشده است. اصل کتاب دوباره مقابله نشده و `partial` / `excerpt-checked` حفظ است.

اجرای اولیهٔ tests/build/browser در sandbox با `spawn EPERM` محدود شد؛ همان گیت‌ها با دسترسی تأییدشده دوباره اجرا و موفق شدند. بازبین مستقل ابهام cloze دو صورت حمام را یافت؛ نمایش cue موجود و آزمون‌های SSR/viewport آن را برطرف کردند. یافتهٔ عملکردی بازی باقی نماند.

تغییرها در working tree مانده‌اند؛ commit، push و انتشار انجام نشده‌اند. `dist/` و `test-results/` خروجی‌های ignored هستند؛ دادهٔ اجرایی بازتولیدشدهٔ `src/content/additional-examples.ts` باید همراه فایل‌های جدید در commit باشد.
