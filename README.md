# Wortzeit

یادگیری واژه‌های آلمانی با راهنمای فارسی؛ React/TypeScript، طراحی از موبایل و PWA آفلاین. حساب، بکاند، دیتابیس سرور و همگام‌سازی ابری ندارد. پیشرفت در IndexedDB همین مرورگر و محتوا در بستهٔ مستقل برنامه نگهداری می‌شوند.

## مرحلهٔ فعال

مسیر درس اول A1 با ۲۰ مدخل منتخب از `reference/vocabulary/Lesson-01-A1.txt`: خانه، «ادامهٔ یادگیری»، حداکثر پنج واژهٔ جدید در هر جلسه، کارت چرخشی، انتخاب معنی، جای خالی، اتصال چهار جفت، خلاصه و فهرست واژه‌ها. مرورهای موعدرسیده مقدم‌اند؛ پاسخ و محل ادامهٔ جلسه با هم ذخیره می‌شوند.

معنی، آرتیکل و تمام ارجاعات موجود برای مدخل‌های منتخب حفظ شده‌اند. مثال‌ها تألیفی‌اند. وضعیت محتوا `excerpt-checked` و پوشش `partial` است؛ تطبیق با این گزیده تأیید جامع اصل کتاب یا تکمیل درس نیست.

## اجرا

Node.js 24 یا بالاتر برای آزمون‌های TypeScript بدون transpiler:

```sh
npm ci
npm run dev -- --host 0.0.0.0
npm test
npm run lint
npm run build
npm run build:portable
npm run verify:dist
npm run preview
npm run test:browser
```

آزمون مرورگر به Chromium نصب‌شدهٔ Playwright نیاز دارد (`npx playwright install chromium`). اجرای PWA و آفلاین روی خروجی production و localhost یا HTTPS بررسی شود؛ HTTP شبکهٔ محلی معمولاً service worker ندارد. برای گوشی واقعی از HTTPS استفاده کنید. `npm run dev` آمادگی آفلاین اعلام نمی‌کند.

در محیط محدود این اجرا، ساخت پردازش `esbuild` رد شد. `npm run build:portable` همان برنامه را با Vite/Rollup و تبدیل TypeScript در همان پردازش می‌سازد؛ خروجی کمینه‌سازی نشده، مستقل از اینترنت و در `dist/` است. `npm run preview` خروجی ساخته‌شده را روی localhost سرو می‌کند. برای این محیط، ابتدا `npm run build:portable` و سپس `npm run preview` اجرا کنید. build عادی برای محیطی با اجازهٔ اجرای esbuild باقی است. `verify:dist` فایل‌ها و رفتار worker را در Node شبیه‌سازی می‌کند؛ شاهد اجرای آفلاین در مرورگر نیست.

نسخه‌های قابل نصب در `package-lock.json` ثابت شده‌اند. قالب اولیه نسخه‌هایی داشت که در محیط محدود قابل دریافت نبودند؛ نسخه‌های موجود و سازگار React 19.2.4، Vite 6.4.1 و TypeScript 5.9.3 جایگزین شدند. lint با ESLint و بررسی hooks اجرا می‌شود.
