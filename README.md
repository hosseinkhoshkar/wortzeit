# Wortzeit

یادگیری واژگان آلمانی با راهنمای فارسی؛ React/TypeScript، موبایل‌محور و PWA. درس اول با همان۲۰ مدخل قبلی و درس چهارم با تمام۸۴ مدخل فایل واژگان، بخش‌های جداگانه و قابل انتخاب دارند. حساب، بکاند، همگام‌سازی و پشتیبان‌گیری وجود ندارند. پیشرفت در IndexedDB همین مرورگر ذخیره می‌شود.

## مرحلهٔ فعال

بخش «درس‌ها» کارت و آمار واقعی هر درس را دارد. درس چهارم مستقیم قابل انتخاب است؛ پیوند `?lesson=lesson-04` نیز آن را باز می‌کند. فلشکارت، انتخاب معنی، جای خالی، اتصال چهار جفت، نوشتن از سرنخ فارسی و آرتیکل اسم‌ها برای هر درس فعال‌اند. مرورها و دشواری‌های همان درس پیش از حداکثر پنج واژهٔ جدید هر جلسه قرار می‌گیرند. جابه‌جایی درس، جلسهٔ قبلی و متن پاسخ آن را نگه می‌دارد.

جلسه هدف حدود ۲۰ دقیقهٔ فعالیت واقعی دارد؛ توقف، مخفی‌بودن و زمان بسته‌بودن برنامه حساب نمی‌شوند. هدف پیشنهاد پایان است و ادامه ممکن است؛ صف خالی می‌تواند زودتر تمام شود. کارت، کمک و حدس مجدد بازی، یادآوری مستقل نیستند. مرورهای موفق در روزهای جدا فاصلهٔ ۱، ۳، ۷، ۱۴ و ۳۰ روز می‌گیرند و مرور بلندمدت ادامه دارد.

نسخه‌های ذخیرهٔ۱ و۲ با حفظ پاسخ، موعد، شناسه، صف و متن به نسخهٔ۳ مهاجرت می‌کنند. هدف۲۰ دقیقه بین درس‌ها مشترک است؛ پیشرفت و جلسهٔ هر درس جدا نمایش داده می‌شوند. نسخهٔ خراب/ناشناخته پاک نمی‌شود. محتوا `partial` و `excerpt-checked` است: تمام۸۴ مدخل فایل درس چهارم پوشش دارند، اما این فایل، تأیید جامع اصل کتاب نیست. مثال‌ها تألیفی‌اند.

## اجرا

Node.js 24 یا بالاتر:

```sh
npm ci
npm run dev -- --host 0.0.0.0
npm test
npm run lint
npm run build
npm run build:portable
npm run verify:dist
npm run preview
npm run test:browser
```

در محیط محدود، اجرای esbuild می‌تواند با EPERM متوقف شود. `build:portable` همان برنامه را با Vite/Rollup و تبدیل درون‌پردازشی TypeScript، بدون کمینه‌سازی، در `dist/` می‌سازد. `preview` خروجی را روی localhost سرو می‌کند. آزمون مرورگر به Chromium نصب‌شدهٔ Playwright نیاز دارد (`npx playwright install chromium`).

آفلاین روی production و localhost/HTTPS معنا دارد؛ HTTP شبکهٔ محلی معمولاً service worker و قفل امن ندارد. `dev` آمادگی آفلاین اعلام نمی‌کند. `verify:dist` artifact و worker را در Node بررسی می‌کند و جای اجرای واقعی مرورگر نیست. محدودیت ابزار و نتیجهٔ واقعی آزمون‌ها در اسناد پذیرش ثبت می‌شوند.
