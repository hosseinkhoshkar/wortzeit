# Wortzeit

یادگیری واژگان آلمانی با راهنمای فارسی؛ React/TypeScript، موبایل‌محور و PWA. درس اول با همان۲۰ مدخل قبلی، درس چهارم با۸۴، درس پنجم با۷۶، درس ششم با۸۰، درس هفتم با۵۵ و درس هشتم با۵۲ مدخل، بخش‌های جداگانه و قابل انتخاب دارند؛ مجموع۳۶۷ مدخل فعال است. حساب، بکاند، همگام‌سازی و پشتیبان‌گیری وجود ندارند. پیشرفت در IndexedDB همین مرورگر ذخیره می‌شود.

## مرحلهٔ فعال

درس ۸ با عنوان **Mmh, das schmeckt! / چه خوشمزه!** و تمام ۵۲ مدخل فایل واژگان فعال است. هر مدخل سه مثال تألیفی دوزبانه دارد. فهرست واژه‌ها و فلش‌کارت‌های تازه بر اساس صفحهٔ چاپی کتاب درسی مرتب‌اند؛ واژه‌های بدون ارجاع کتاب درسی در انتهای درس می‌آیند.

برای شنیدن تلفظ در واژه‌نامه، مثال‌ها و بازخورد پاسخ، متن آلمانیِ دارای زیرخط نقطه‌چین را لمس کن. فلش‌کارت‌ها، بازی اتصال و سؤال‌های انتخابی دکمهٔ بلندگو دارند. پخش با صدای مرورگر و سرعت پیش‌فرض انجام می‌شود. وجود صدای آلمانی و امکان پخش آفلاین به دستگاه بستگی دارد. [دامنه و بررسی تلفظ](docs/pronunciation.md).

بخش «درس‌ها» کارت و آمار واقعی هر درس را دارد. درس‌ها مستقیم از کارت خودشان قابل انتخاب‌اند؛ پیوند `?lesson=lesson-08` درس هشتم را باز می‌کند. فلشکارت، انتخاب معنی، جای خالی، اتصال چهار جفت، نوشتن از سرنخ فارسی و آرتیکل اسم‌ها برای هر درس فعال‌اند. مرورها و دشواری‌های همان درس پیش از حداکثر پنج واژهٔ جدید هر جلسه قرار می‌گیرند. جابه‌جایی درس، جلسهٔ قبلی و متن پاسخ آن را نگه می‌دارد.

جلسه هدف حدود ۲۰ دقیقهٔ فعالیت واقعی دارد؛ توقف، مخفی‌بودن و زمان بسته‌بودن برنامه حساب نمی‌شوند. هدف پیشنهاد پایان است و ادامه ممکن است؛ صف خالی می‌تواند زودتر تمام شود. کارت، کمک و حدس مجدد بازی، یادآوری مستقل نیستند. مرورهای موفق در روزهای جدا فاصلهٔ ۱، ۳، ۷، ۱۴ و ۳۰ روز می‌گیرند و مرور بلندمدت ادامه دارد.

نسخه‌های ذخیرهٔ۱،۲ و۳ با حفظ پاسخ، موعد، شناسه، صف و متن به نسخهٔ۴ مهاجرت می‌کنند. افزودن درس‌های ۵ تا ۸، schema۴ و شناسهٔ سازگاری `course-a1-lessons-01-04-v1` را حفظ می‌کند؛ ذخیره‌های قبلی به تغییر نسخه نیاز ندارند. هدف۲۰ دقیقه بین درس‌ها مشترک است؛ پیشرفت و جلسهٔ هر درس جدا نمایش داده می‌شوند. نسخهٔ خراب/ناشناخته پاک نمی‌شود. محتوا `partial` و `excerpt-checked` است: همهٔ مدخل‌های فایل‌های گزیدهٔ درس‌های ۴ تا ۸ پوشش دارند، اما این فایل‌ها تأیید جامع اصل کتاب نیستند. مثال‌ها تألیفی‌اند.

## تجربهٔ تازهٔ یادگیری

خانهٔ خلوت با رنگ‌های یاسی/نعنایی و فونت فارسی محلی. جلسه‌های تازه ابتدا تا پنج فلش‌کارت را پشت‌سرهم نشان می‌دهند، سپس تمرین همان واژه‌ها آغاز می‌شود. مرورهای موعدرسیده و جلسه‌های ناتمام اولویت دارند. در بازی اتصال، بازخورد کوتاه و ادامه خودکار است؛ خطا گزینه‌ها را موقتاً قرمز می‌کند و انتخاب دوباره آزاد می‌شود. ذخیرهٔ زمان و متن پاسخ، دکمه‌های صفحه را چشمک‌زن یا غیرفعال نمی‌کند.

## مرور معکوس و صفحهٔ موبایل

صفحهٔ اصلی و تمرین‌های موبایل با ارتفاع واقعی صفحه تنظیم می‌شوند و دکمهٔ اصلی در همان نما می‌ماند؛ توضیحات در پنجرهٔ جزئیات و فهرست‌های طولانی در ناحیهٔ داخلی در دسترس‌اند. کیبورد، راهنمای پاسخ را حذف نمی‌کند.

پس از تکمیل۱۵ واژهٔ یکتا (شناخت معنی بدون کمک، یادآوری نوشتاری مستقل، و آرتیکل صحیح برای اسمِ دارای آرتیکل)، حداکثر۲ کارتِ موعدرسیدهٔ فارسی→آلمانی در نوبت‌های تازه با همان حداکثر۵ واژهٔ جدید مخلوط می‌شوند. کارت می‌تواند از درس قبلی باشد؛ درس انتخاب‌شده عوض نمی‌شود. پاسخ آلمانی پس از «نمایش پاسخ» باز می‌شود و ارزیابی شخصی «درست گفتم/اشتباه گفتم» جدا از مهارت نوشتن ذخیره می‌شود.

اولین موعد روز بعد است؛ موفقیت‌ها فاصله‌های۳،۷،۱۴،۳۰ روز و سپس افزایش۳۰روزه تا سقف۳۶۵ روز دارند. خطا، مرور را به روز بعد می‌برد و همان جلسه تکرار نمی‌شود. تاریخ‌ها با روز تقویمی منطقهٔ مطالعه و تغییر ساعت تابستانی محاسبه می‌شوند؛ زمان‌بندی نوشتاری قبلی حفظ شده است. اگر موعدی نرسیده باشد، کارت معکوس اضافی ساخته نمی‌شود. پایان واژه‌های جدید مانع مرور نمی‌شود.

[برنامه و قرارداد مرور معکوس](docs/reverse-review-plan.md) و [پذیرش و راهنمای بررسی](docs/reverse-review-acceptance.md).

## مثال‌های تازه

برای تمام۳۰فایل مرجع و۱۳۳۳مدخل، دو مثال تألیفی آلمانی با ترجمهٔ فارسی در `public/content/examples/` آماده شده است. شش درس فعال اپ (۳۶۷ واژه) هر کدام یک مثال اولیه و دو مثال تکمیلی دارند؛ مثال‌های قبلی درس۱ و۴ حفظ شده‌اند. دیگر فایل‌های مرجع به درس فعال تبدیل نشده‌اند.

در معرفی اولیه فقط مثال فعلی دیده می‌شود. مرور معکوس بعد از نمایش جواب، مثال‌های دوم، سوم و اول را به‌ترتیب رخدادهای کاملِ مرور می‌چرخاند. «مثال‌های بیشتر» اختیاری و بدون اثر بر موعد یا امتیاز است. همهٔ داده‌ها با نسخهٔ جدید در cache آفلاین قرار می‌گیرند.

`npm run sync:examples` پوشش و سازگاری را بررسی و دادهٔ اجرایی را قطعی می‌سازد؛ `build` و `build:portable` این مرحله را خودکار انجام می‌دهند. [گزارش شمارش، تست و بررسی دستی](docs/examples-acceptance.md).

## اجرا

Node.js 24 یا بالاتر:

```sh
npm ci
npm run dev -- --host 0.0.0.0
npm test
npm run lint
npm run build
npm run build:portable
npm run verify:dist
npm run preview
npm run test:browser
```

در محیط محدود، اجرای esbuild می‌تواند با EPERM متوقف شود. `build:portable` همان برنامه را با Vite/Rollup و تبدیل درون‌پردازشی TypeScript، بدون کمینه‌سازی، در `dist/` می‌سازد. `preview` خروجی را روی localhost سرو می‌کند. آزمون مرورگر به Chromium نصب‌شدهٔ Playwright نیاز دارد (`npx playwright install chromium`).

آفلاین روی production و localhost/HTTPS معنا دارد؛ HTTP شبکهٔ محلی معمولاً service worker و قفل امن ندارد. `dev` آمادگی آفلاین اعلام نمی‌کند. `verify:dist` artifact و worker را در Node بررسی می‌کند و جای اجرای واقعی مرورگر نیست. محدودیت ابزار و نتیجهٔ واقعی آزمون‌ها در اسناد پذیرش ثبت می‌شوند.
